# Posada Navideña 2026

Página de la posada: info, contador, intercambio con código y votación de premios (Formspree).

## Archivos
- `index.html`, `style.css`, `script.js`: la página
- `data.js`: sorteo cifrado (cada resultado solo se abre con el código de esa persona)
- `CNAME`: dominio `posada2026.xyz`
- `.nojekyll`: hace que GitHub Pages publique los archivos tal cual

## Editar textos
En `script.js`, bloque `CONFIG`: preguntas, actividades, fecha y enlace del mapa.
**No edites `invitados` a mano**: la lista de invitados va ligada al sorteo de `data.js`.
